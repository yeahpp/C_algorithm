| 종류                      | 네가 사용한 구조              | 끝 판단      | 첫 노드           | 마지막 노드       | 뒤 삽입/삭제          | 주로 언제 쓰나                   |
| ----------------------- | ---------------------- | --------- | -------------- | ------------ | ---------------- | -------------------------- |
| **비원형 단일 연결 리스트 (SLL)** | `head` 더미 1개           | `NULL`    | `head->next`   | 순회해서 찾음      | O(n)             | 단순한 순차 데이터, 한 방향 탐색만 필요할 때 |
| **비원형 이중 연결 리스트 (DLL)** | `head + tail` 더미       | `tail`    | `head->next`   | `tail->prev` | **O(1)**         | 앞/뒤 이동·삽입·삭제가 모두 중요할 때     |
| **원형 단일 연결 리스트 (CSLL)** | 보통 `head` 또는 `tail` 관리 | 다시 시작 노드  | `head->next` 등 | 구조에 따라 다름    | `tail` 관리 시 O(1) | 데이터를 계속 순환해야 할 때           |
| **원형 이중 연결 리스트 (CDLL)** | **더미 `head` 1개** 추천    | 다시 `head` | `head->next`   | `head->prev` | **O(1)**         | 양방향 이동 + 순환이 모두 필요할 때      |
